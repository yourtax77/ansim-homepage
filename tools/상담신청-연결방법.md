# 상담 신청 → 구글 시트 + 이메일 연결 방법

홈페이지 상담 신청 내용이 **구글 시트에 한 줄씩 쌓이고**, 동시에 **알림 메일**이 오도록 연결합니다.
처음 한 번만 설정하면 됩니다. (약 10분)

## 1. 구글 시트 만들기
1. 사무소 구글 계정으로 [sheets.new](https://sheets.new) 를 열어 새 시트를 만듭니다.
2. 시트 이름을 `안심상속센터 상담신청` 으로 바꿉니다.

## 2. 접수 스크립트 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
2. 편집기에 있던 내용을 모두 지우고, `tools/consult-apps-script.gs` 파일 내용을 그대로 붙여넣습니다.
3. 맨 위 `NOTIFY_EMAIL = 'office@example.com'` 을 **알림 받을 이메일 주소**로 바꿉니다.
4. 저장(디스크 아이콘)을 누릅니다.

## 3. 테스트 (권한 허용)
1. 위쪽 함수 선택 칸에서 `testSubmit` 을 고르고 **실행**을 누릅니다.
2. 구글이 권한을 묻습니다. 본인 계정을 고르고 **허용**합니다.
   - "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동**을 누릅니다. 본인이 만든 스크립트라 안전합니다.
3. 시트에 `상담신청` 탭이 생기고 테스트 줄이 들어오면, 알림 메일도 왔는지 확인합니다.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱** 을 고릅니다.
3. 설정:
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 를 누르면 `https://script.google.com/macros/s/.../exec` 형태의 **웹 앱 URL** 이 나옵니다. 복사합니다.

## 5. 홈페이지에 연결
- `office.js` 의 `consultEndpoint: ''` 따옴표 안에 위 URL 을 넣습니다. (또는 Claude에게 URL을 알려주면 넣어 드립니다.)

## 참고
- 시트의 **처리 상태** 칸에 `연락 완료`, `계약` 등을 적어 관리하면 됩니다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (URL은 그대로 유지)
- 상담 신청에는 개인정보(성함·연락처)가 담기므로 시트는 사무소 내부에서만 공유하세요.
- 개인정보처리방침 페이지에 "수집 항목, 이용 목적, 보관 기간, 위탁(구글)" 내용을 함께 적어야 합니다.
